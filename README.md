# Cycle Cue

A cycle companion for partners, built with Capacitor for iOS and Android.

- `www/` contains the app (a single HTML file)
- `assets/` contains the icon and splash source images
- `docs/` holds the support and privacy pages, hosted with GitHub Pages
- `.github/workflows/` has the cloud builds for Android (.aab) and iOS (TestFlight)
- `PUBLISHING.md` gives the step-by-step store submission plan
- `STORE-LISTING.md` has all the store text and form answers
